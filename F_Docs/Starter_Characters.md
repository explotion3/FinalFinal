## 3. 霍断岳

### 3.1 角色定位
一句话定位：霍断岳是首发阵容中的破阵核心，负责用稳定削韧打开 Break 窗口，并在高压局面下维持可兑现的反打能力。

核心职责：
* 稳定削韧
* 承接压力
* 收割 Break 目标

### 3.2 专属机制
机制名：`刀势`

核心作用：
* 让攻击持续带削韧收益
* 服务 Break 前后节奏

默认用法：
* 获得 `刀势` 时按层数累积
* starter 第一波 Runtime 中，`刀势` 通过已配置的霍断岳牌明确获得与消耗
* 当前已落地的受击触发口径为：当霍断岳所属队伍生命实际受损时，霍断岳通过共享 `RuntimeTriggerDefinition` 的 `OwnerTookHealthDamage` trigger 获得 `1` 层 `刀势`
* 当前已落地的最小兑现口径为：被配置为“消耗刀势”的攻击牌，在消耗 `1` 层后额外造成削韧
* 当前已落地的 Break 条件口径为：`Damage` effect 通过 `Effect.Conditions[]` 里的 `TargetState` 条件要求目标敌人处于 Break；霍断岳奥义已用该协议兑现 Break 目标额外伤害

## 4. 叶半夏

### 4.1 角色定位
一句话定位：叶半夏是首发阵容中的回血辅助核心，负责用低费牌稳定队伍血线、提供生命免疫，并通过药引把治疗转化为额外续航或 AP 修正。

核心职责：
* 低费续航
* 施加生命免疫
* 修正资源

### 4.2 专属机制
机制名：`药引`

核心作用：
* 作为治疗、生命免疫与 AP 修正的转化入口
* 区分直接治疗与资源型治疗

默认用法：
* 获得 `药引` 时按层数累积
* `药引` 默认不自动生效，只有被牌明确消耗时才结算收益

| `化引` | 技能牌 | `1 AP` | 药引转节奏 |
| `回春散` | 技能牌 | `1 AP` | 急救稳场 |

## 5. 沈清弦

### 5.1 角色定位
一句话定位：沈清弦是首发阵容中的战术辅助核心，负责布置剑阵、帮助队友过牌，并把剑阵转成全队的增伤与爆发窗口。

核心职责：
* 剑阵联动
* 过牌支援
* 团队爆发铺垫

### 5.2 专属机制
机制名：`剑阵`

核心作用：
* 作为过牌、增伤、削韧放大与连段支援的入口
* 区分直接伤害牌与铺收益牌

默认用法：
* 相关牌或效果会生成对应的剑阵牌到手牌
* 剑阵牌属于衍生牌，默认 `0 AP`，并带 `保留` 与 `消耗`
* 剑阵牌默认不进入普通牌组循环
* starter 第一波 Runtime 已落地：`布锋` 随机生成剑阵牌、`引阵` 稳定生成 `过牌剑阵`、`引爆剑阵` 真实消耗 1 张手中的衍生剑阵牌
* 当前 Battle 还补了最小 `HandCardRequirement` 协议，`守阵` 已用它真实检查“手中是否存在衍生剑阵牌”
* 当前 Battle 也已补最小“状态驱动的攻击修正”协议，`锋锐剑阵` 与 `万象归阵` 的 `锋锐 / 士气` 都已进入 Battle Runtime
