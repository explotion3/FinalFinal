# 首章事件内容

## 1. 文档定位
本文档用于统一维护首章事件内容。  
只收事件相关内容，不收角色、敌人、遗物。

使用边界如下：
* 系统定位与总纲，以 `GDD4.0.md` 为准
* 规则定义与结算时序，以 `Battle_Rules.md` 为准
* 具体数值区间，以 `Numbers_FirstPass.md` 为准

## 2. 首章事件总览
首章事件设计目标：
* 让玩家在第一章就遇到控压、换资源、换遗物、换成长的明确抉择
* 事件奖励优先围绕金币、删牌、升级、遗物、角色成长、压力管理
* 首版事件尽量少用复杂持久 Run 标记，优先使用可直接结算的代价与收益

| 事件 | 类型 | 出现条件 | 核心作用 |
| --- | --- | --- | --- |
| `山道茶棚` | 压力调整事件 | 无 | 低风险控压与经济交换 |
| `断桥镖车` | 代价换收益 | 无 | 用生命或金钱换高价值资源 |
| `黑风寨暗哨` | 风险试探 | 无 | 以压力换金币或删牌机会 |
| `旧刀试锋石` | 角色成长事件 | 队伍中有霍断岳 | 推进霍断岳破阵 / 反斩方向 |
| `残庙药案` | 角色成长事件 | 队伍中有叶半夏 | 推进叶半夏稳场 / 药引方向 |
| `乱阵石坪` | 角色成长事件 | 队伍中有沈清弦 | 推进沈清弦阵牌 / 过牌方向 |
| `静心岩洞` | 休整事件 | 无 | 强控压或删牌修整 |
| `失主行囊` | 神秘交易 | 无 | 赌博式换遗物 / 金钱 / 压力 |
| `风雨旧亭` | 休整事件 | 无 | 小幅回血、控压或换取一点经济 |

## 3. 通用事件

### 3.1 山道茶棚
类型：`压力调整事件`

定位：首章最基础的控压事件，让玩家理解“花钱稳状态”与“贪资源吃压力”的权衡。

选项：
* `花费 35 金。` 全部角色降低 `3` 点压力。
* `赊一壶苦茶。` 选择 `1` 名角色降低 `6` 点压力；队伍失去 `8` 点生命。
* `掀桌夺财。` 获得 `70` 金；全部角色增加 `3` 点压力。

### 3.2 断桥镖车
类型：`代价换收益`

定位：首章的高收益资源事件，优先提供遗物和金币，但明确伴随风险。

选项：
* `强行拆车。` 队伍失去 `16` 点生命；获得 `1` 个随机稀有遗物。
* `捡走散货。` 获得 `90` 金；随机 `1` 名未崩溃角色增加 `4` 点压力。
* `扶正残车。` 回复 `18` 点生命；获得 `40` 金。

### 3.3 黑风寨暗哨
类型：`风险试探`

定位：首章的高波动事件，用于给玩家提供“冒险换删牌 / 金币”的机会。

选项：
* `摸掉岗哨。` 选择移除牌组中的 `1` 张牌；随机 `1` 名未崩溃角色增加 `5` 点压力。
* `绕路避开。` 无事发生。
* `搜走哨银。` 获得 `80` 金；队伍失去 `10` 点生命。

### 3.4 静心岩洞
类型：`休整事件`

定位：首章最稳定的修整点，用于在精英战或首领战前做强控压或牌组修整。

选项：
* `静坐调息。` 全部角色降低 `5` 点压力。
* `吐纳归元。` 回复队伍 `25%` 当前缺失生命。
* `断念弃牌。` 移除牌组中的 `1` 张牌；随机 `1` 名角色增加 `2` 点压力。

### 3.5 失主行囊
类型：`神秘交易`

定位：首章的赌博事件，让玩家在“稳妥金币”与“高波动遗物”之间选择。

选项：
* `原样归还。` 获得 `60` 金。
* `私开行囊。` 获得 `1` 个随机普通遗物；随机 `1` 名未崩溃角色增加 `4` 点压力。
* `强拆夹层。` 获得 `1` 个随机稀有遗物；队伍失去 `14` 点生命；全部角色增加 `2` 点压力。

### 3.6 风雨旧亭
类型：`休整事件`

定位：首章的中性修整事件，用来补足事件池密度，并给节点流更多低波动选择。

选项：
* `借火歇息。` 回复 `20` 点生命。
* `稳住心神。` 全部角色降低 `3` 点压力。
* `掀开地砖。` 获得 `45` 金；随机 `1` 名角色增加 `2` 点压力。

## 4. 角色成长事件

### 4.1 旧刀试锋石
类型：`角色成长事件`

出现条件：队伍中有 `霍断岳`

定位：推进霍断岳的破阵、守势与终结成长方向。

选项：
* `试破锋。` 将霍断岳的 `1` 张攻击牌升级；优先提供偏削韧方向的升级。
* `试守势。` 将霍断岳的 `1` 张技能牌升级；若无可升级牌，则获得 `1` 张 `铁壁回锋`。
* `留痕于石。` 获得 `1` 张 `破军式`；霍断岳增加 `3` 点压力。

### 4.2 残庙药案
类型：`角色成长事件`

出现条件：队伍中有 `叶半夏`

定位：推进叶半夏的治疗、药引与免疫方向。

选项：
* `整理药案。` 将叶半夏的 `1` 张牌升级；优先提供偏稳场 / 治疗方向的升级。
* `试配药引。` 获得 `1` 张 `回春散`；叶半夏降低 `2` 点压力。
* `吞下烈药。` 叶半夏增加 `4` 点压力；队伍回复 `20` 点生命；随机 `1` 名角色降低 `2` 点压力。

### 4.3 乱阵石坪
类型：`角色成长事件`

出现条件：队伍中有 `沈清弦`

定位：推进沈清弦的阵牌生成、过牌与引爆节奏。

选项：
* `补刻阵痕。` 将沈清弦的 `1` 张牌升级；优先提供偏阵牌 / 支援方向的升级。
* `临阵推演。` 获得 `1` 张 `引爆剑阵`。
* `散阵试手。` 从 `引阵 / 引爆剑阵` 中获得 `1` 张；抽 `1` 张牌；沈清弦增加 `3` 点压力。

## 5. 首版制作项
必做内容：
* 通用事件 `5` 个
* 角色成长事件 `3` 个
* 明确带压力调整的事件至少 `3`
* 明确带删牌、升级、遗物收益的事件至少各 `1`
* 首版事件优先采用 `2~3` 选项结构，不做长链分支
