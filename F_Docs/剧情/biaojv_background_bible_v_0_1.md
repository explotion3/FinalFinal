# 镖局背景设定文档 v0.1

> 文档用途：保存当前已经确定的游戏背景方向，并为后续扩充人物、镖种、章节、事件、卡牌、遗物、局外成长等内容提供统一基准。
>
> 当前版本重点：先确定“镖局押镖”作为游戏世界与单局 Run 的核心框架。人物设定暂不展开，后续另行设计。

---

## 1. 当前已定背景版本

天下商路渐乱，官府管不到山野，门派不再庇护百姓，商会只认银钱，山寨占路为王。

在这样的世道里，镖局成了连接城镇、村寨、门派、官府和黑市的最后一类人。

玩家接手一家濒临倒闭的老镖局。它曾经声名显赫，却因多年前一趟“无名旧镖”一落千丈。老镖头失踪，账本残缺，旧人散尽，只剩一面破旧镖旗。

为了还债、重振门面，也为了查清旧镖案，玩家必须重新接镖上路。

每一趟镖都是一次 Run：可能是送货、护人、押棺、送信、赎人、运暗箱，甚至只是打着镖旗走一条没人敢走的路。

玩家要在路途中面对劫匪、黑店、官差、山寨、商会、门派和委托人的谎言。

有些镖必须送到，有些镖不该送到。

镖局真正经营的不是银两，而是信用。

而当一趟趟新镖把旧账重新翻开，玩家会发现：当年那趟失踪旧镖，可能正是如今江湖变乱的起点。

---

## 2. 核心定位

### 2.1 游戏世界关键词

- 市井武侠
- 镖局经营
- 路途冒险
- 委托悬疑
- 旧案追查
- 信用与道义
- 乱世夹缝中的生意与人情

### 2.2 游戏叙事核心

玩家不是天选英雄，也不是名门少侠，而是一家衰败镖局的新任掌局者。

玩家的首要目标不是拯救天下，而是让镖局活下去：还债、接镖、守信、养人、修车、开路、重振门面。

但随着一趟趟新镖完成，玩家会逐渐接近多年前“无名旧镖”的真相。镖局的衰败、老镖头的失踪、商路的混乱、各方势力的异常行动，可能都与那趟旧镖有关。

### 2.3 游戏体验目标

每一次 Run 都应该让玩家感觉自己是在完成一趟具体的镖，而不是抽象地进入一场随机冒险。

玩家每次出发前都应知道：

- 这趟镖要送什么；
- 谁委托了这趟镖；
- 要送到哪里；
- 有什么规矩；
- 违反契约会付出什么代价；
- 路上可能遇到什么麻烦。

玩家每次回到镖局时都应感觉：

- 镖局的处境发生了变化；
- 某些人对镖局的态度发生了变化；
- 某条商路、某个势力、某段旧账被推进了一点；
- 镖局作为“家”的存在感变强了一点。

## 3. 玩家据点：濒临倒闭的老镖局

### 3.1 镖局基础设定

玩家接手的镖局曾经声名显赫，镖旗一出，山寨让路，商会给面子，官道也愿意通融。

但多年前一趟“无名旧镖”之后，镖局彻底衰败：

- 老镖头失踪；
- 参与旧镖的人死的死、散的散、隐姓埋名；
- 账本残缺，关键页数被撕走；
- 镖局背负债务与赔偿；
- 旧客户不再信任；
- 门面破败，车马损坏，镖旗蒙尘。

玩家接手后，镖局既是局外成长空间，也是剧情主线的核心载体。

### 3.2 镖局的设计目标

镖局不应只是功能菜单，而应是玩家的“家”。

玩家应当通过一次次 Run 逐步修复它、扩建它、重新点亮它，让它从破败老宅变回真正的镖局。

### 3.3 可扩充区域

| 区域 | 功能方向 | 剧情作用 |
|---|---|---|
| 镖局大堂 | 接镖、查看委托、选择下一趟 Run | 镖局门面，体现声望变化 |
| 账房 | 查看银两、债务、赔偿、契约记录 | 体现经营压力与旧账线索 |
| 镖车棚 | 改装镖车、选择货箱、防护方式 | 影响押镖过程与货物安全 |
| 马厩 | 管理马匹、路线速度、急镖能力 | 体现路途感与运输能力 |
| 武备房 | 准备护镖工具、武器、防具、消耗品 | 连接卡牌、道具与战斗准备 |
| 药房 | 处理伤病、准备药材、降低出发风险 | 连接长期损耗与恢复系统 |
| 客舍 | 临时镖师、委托人、过路人停留 | 触发人物与委托事件 |
| 旧账库 | 存放旧契约、残缺账本、旧案卷 | 推进“无名旧镖”主线 |
| 镖旗堂/祠堂 | 供奉旧镖旗，纪念死去镖师 | 作为情绪锚点与镖局精神象征 |

## 4. 单局 Run 的叙事结构

每一次 Run 在剧情上都是一趟镖。

建议基础流程为：

```text
接镖 → 验镖 → 备镖 → 选路 → 上路 → 路途事件/战斗 → 交镖 → 回局结算
```

### 4.1 接镖

玩家在镖局大堂选择委托。

每份委托应尽量像真实契约，而不是单纯任务列表。

建议包含：

- 委托名称；
- 委托人；
- 镖种；
- 货物或护送对象；
- 目的地；
- 推荐路线；
- 报酬；
- 违约赔偿；
- 特殊规矩；
- 风险等级；
- 是否与主线或旧镖案有关。

### 4.2 验镖

出发前，玩家可以选择是否验货。

验镖是镖局题材的重要特色，代表“守规矩”和“保命”之间的冲突。

可选方式：

| 验镖方式 | 结果方向 |
|---|---|
| 不验 | 严守契约，但对风险一无所知 |
| 粗验 | 不破坏封条，只确认大致类别 |
| 细验 | 获得更多情报，但可能损害委托人信任 |
| 偷看 | 直接获得关键秘密，但可能留下后患 |

### 4.3 备镖

玩家根据镖种和路线准备资源。

可准备内容包括：

- 镖车配置；
- 马匹；
- 药品；
- 护具；
- 消耗道具；
- 临时雇员；
- 通关文书；
- 路引；
- 伪装货箱；
- 备用车轴。

### 4.4 选路

不同路线应带来不同风险、事件与敌人。

| 路线 | 特点 |
|---|---|
| 官道 | 稳定，但可能遇到查验、税卡、官府刁难 |
| 山路 | 快捷，但山匪、野兽、塌方、伏击较多 |
| 水路 | 节省体力，但会遇水寇、风浪、封渡、货物受潮 |
| 旧商道 | 奖励和线索较多，但废弃驿站与诡异事件多 |
| 小路 | 可避开强敌，但容易迷路、延误或错过补给 |
| 黑道 | 依赖地下人脉，安全与否取决于代价 |

### 4.5 路途节点

路途中可出现：

- 战斗；
- 伏击；
- 驿站；
- 岔路；
- 黑店；
- 天气变化；
- 货物异常；
- 委托人插手；
- 临时交易；
- 官府盘查；
- 山寨拦路；
- 人镖对象提出要求；
- 暗镖发出异响；
- 镖车损坏；
- 追兵逼近；
- 旧镖案线索出现。

### 4.6 交镖

交镖不应永远等于胜利。

可能结果：

| 结果 | 含义 |
|---|---|
| 完整交付 | 货物完好，获得完整报酬与信誉 |
| 破损交付 | 报酬减少，可能引发争执 |
| 延误交付 | 货物还在，但错过关键时机 |
| 改交他人 | 玩家主动违约，可能救人或得罪委托人 |
| 拒绝交付 | 玩家发现委托有问题，选择毁约 |
| 货物失踪 | 任务失败，产生赔偿或声望损失 |
| 交付后反转 | 收货人、委托人或货物真相发生变化 |

## 5. 镖种体系

镖种是后续内容扩充的核心分类。每种镖都应是一种不同的故事容器，也可以对应不同的 Run 规则。

### 5.1 普通镖

常规货物押送。

可能货物：

- 茶叶；
- 布匹；
- 药材；
- 盐铁；
- 瓷器；
- 粮草；
- 银箱；
- 兵器；
- 书籍；
- 香料；
- 酒坛。

设计重点：

- 体现江湖日常；
- 适合作为早期与普通委托；
- 可以通过货物属性制造事件。

示例规则方向：

| 货物 | 特点 |
|---|---|
| 瓷器 | 易碎，镖车受损会影响报酬 |
| 药材 | 怕潮，可在路上救人但会减少交货量 |
| 银箱 | 吸引劫匪，也考验队伍与玩家选择 |
| 粮草 | 重，拖慢路线，容易触发灾民事件 |
| 兵器 | 被劫后可能让敌人势力增强 |

### 5.2 人镖

护送某个人到达目的地。

可能对象：

- 逃婚者；
- 证人；
- 账房先生；
- 失忆剑客；
- 重伤病人；
- 新任官员；
- 叛逃门派弟子；
- 被追杀的孩子；
- 被押解的犯人；
- 身份不明的贵客。

设计重点：

- 护送对象会说话、隐瞒、害怕、逃跑或提出要求；
- 人镖应带来强剧情和强事件；
- 护送对象本身可以是麻烦的源头。

可能特性：

| 特性 | 效果方向 |
|---|---|
| 胆小 | 战斗受伤后压力上升 |
| 隐瞒身份 | 中途吸引特殊敌人 |
| 重伤 | 需要持续消耗药物 |
| 通缉 | 走官道风险提升 |
| 嘴硬 | 容易激怒敌人或 NPC |
| 有人脉 | 在驿站、城镇可能获得帮助 |
| 会武功 | 可支援战斗，但可能暴露身份 |

### 5.3 暗镖

高报酬、高规矩、不可问不可看的镖。

常见规矩：

- 不得开箱；
- 不得询问；
- 不得改道；
- 不得让第三人接触；
- 不得在夜间停留；
- 若货物有异响，不得理会；
- 必须在指定时辰交付。

设计重点：

- 暗镖强调悬疑；
- 玩家需要在好奇心、风险和契约之间选择；
- 暗镖非常适合承载主线旧镖案。

可能真相：

| 暗镖真相 | 剧情方向 |
|---|---|
| 箱中是人 | 可能是绑架，也可能是救人 |
| 箱中是尸体 | 死者身份牵出旧案 |
| 箱中是兵符 | 各方势力争夺 |
| 箱中是禁药 | 路上敌人或事件逐渐异常 |
| 箱中是空的 | 玩家只是诱饵 |
| 箱中是账本 | 牵涉官府、商会或门派 |
| 箱中是活物 | 夜晚或战斗后产生变化 |
| 箱中是旧镖局之物 | 牵出“无名旧镖”主线 |

### 5.4 死镖

送尸、送骨、送遗物、送遗书。

可能内容：

- 棺材；
- 骨灰；
- 遗书；
- 断剑；
- 战死者遗物；
- 仇人的头颅；
- 无名尸首；
- 某门派失踪弟子的遗物。

设计重点：

- 死镖强调情绪、迟来的真相和旧债；
- 收货的人往往比货物更重要；
- 适合中后期剧情和章节 Boss。

### 5.5 急镖

限时送达的镖。

可能委托：

- 救命药必须三日内送到；
- 军令必须天亮前送达；
- 证人必须赶在开审前抵达；
- 赎金必须在期限内交付；
- 婚书必须在拜堂前送到。

设计重点：

- 急镖强调时间压力；
- 玩家需要在安全、速度、资源消耗之间取舍；
- 可引入超时、赶路、换马、放弃休息等机制。

### 5.6 官镖

与官府相关的镖。

可能内容：

- 税银；
- 官印；
- 文书；
- 囚犯；
- 贡品；
- 军械；
- 案卷；
- 通缉犯押送；
- 新官赴任护送。

设计重点：

- 官府不一定代表秩序；
- 适合表现腐败、栽赃、权力斗争；
- 可连接地方官、捕快、税卡、军队、案卷等系统。

### 5.7 赎镖

带着赎金、信物或交换条件去换人或换货。

可能委托：

- 商会少东家被绑；
- 镖局旧人被抓；
- 某门派弟子被扣；
- 一批货被山寨截走；
- 委托人要求不能报官；
- 绑匪要求独自前往。

设计重点：

- 赎镖强调谈判、埋伏和反转；
- 终点不一定是战斗，也可能是交易选择；
- 适合体现江湖规矩。

### 5.8 空镖

没有实际货物，却要求镖局打着镖旗走完某条路线。

可能原因：

- 吸引敌人现身；
- 替真正的货物做诱饵；
- 测试某条路是否安全；
- 给某个地方传递“镖局还活着”的信号；
- 让别人误以为货在玩家手上；
- 重走当年某趟旧镖的路线。

设计重点：

- 空镖强调“局”；
- 适合主线和高难挑战；
- 可以让玩家意识到，押镖有时送的不是东西，而是某种信号。

### 5.9 反镖

反镖不是初始镖种，而是某些委托中途变质后的状态。

触发方式：

- 发现药镖其实是毒；
- 发现护送对象是凶手；
- 发现暗箱里是被拐的孩子；
- 发现案卷会害死无辜者；
- 发现收货方并非真正收货人。

玩家可选：

- 继续送，守契约；
- 毁镖，守良心；
- 改交他人；
- 私下调查；
- 敲诈委托人；
- 公开真相。

设计重点：

镖局题材的核心矛盾之一：镖师到底是守货，还是守道义？

## 6. 镖局经营核心：信用

镖局真正经营的不是银两，而是信用。

银两用于修复、雇人、备货、赔偿和扩建；信用决定谁愿意把更重要、更危险、更有故事的镖交给玩家。

建议将声望拆分为多个维度，而不是单一善恶值。

| 声望类型 | 代表 |
|---|---|
| 商道信誉 | 商会、货主是否愿意托镖 |
| 江湖名声 | 门派、镖局、山寨是否给面子 |
| 官府关系 | 通关、查验、官镖机会 |
| 民间口碑 | 百姓、村镇、驿站是否愿意帮忙 |
| 黑道忌惮 | 匪帮、水寇、地下势力是否避让 |
| 契约评价 | 是否守时、守密、守货、守规矩 |

不同玩家选择会造成不同倾向：

- 经常毁约救人：民间口碑高，商道信誉可能降低；
- 严格守约：商道信誉高，但可能显得冷血；
- 与黑道交易：路途更安全，但官府关系受损；
- 常常开箱查验：安全性提高，但委托人信任降低；
- 从不违约：高级商会更信任，但可能错过隐藏真相。

## 7. 货物与镖车系统扩充方向

为了让“送货”成为玩法核心，后续可以将货物与镖车设计成独立系统。

### 7.1 货物属性

| 属性 | 影响方向 |
|---|---|
| 价值 | 影响报酬，也影响敌人兴趣 |
| 重量 | 影响行进速度与路线选择 |
| 易损 | 影响战斗、伏击、天气后的破损风险 |
| 保密 | 是否允许开箱，是否影响信用 |
| 危险 | 货物本身是否会出事 |
| 腐坏 | 是否存在时间压力 |
| 招灾 | 是否吸引特殊敌人或事件 |
| 体积 | 影响能否携带额外物资 |

### 7.2 镖车配置

| 配置 | 作用方向 |
|---|---|
| 加固车厢 | 降低货物破损 |
| 暗格 | 适合暗镖，降低被查风险 |
| 轻车轮 | 提升速度，降低载重 |
| 铁皮箱 | 防劫掠，但更显眼 |
| 遮雨棚 | 保护药材、书籍、布匹等怕潮货物 |
| 马铃 | 降低突袭概率，但容易暴露行踪 |
| 伪装货箱 | 降低敌人判断货物价值 |
| 备用车轴 | 应对路途损坏 |

## 8. 主线核心：无名旧镖

### 8.1 旧镖案定位

“无名旧镖”是贯穿整个游戏的主线谜团。

它不是开局就完全揭露的大事件，而是通过一趟趟新镖逐渐拼出来的旧案。

### 8.2 已定信息

- 多年前，玩家接手的老镖局曾接下一趟特殊镖；
- 这趟镖在账本中没有完整名称，因此被称为“无名旧镖”；
- 旧镖之后，老镖头失踪；
- 镖局声望崩塌；
- 账本残缺，关键页数被撕走；
- 当年参与者大多死亡、失踪或隐姓埋名；
- 当前江湖商路的混乱，可能与那趟旧镖有关。

### 8.3 待扩充问题

后续需要逐步确定：

- 当年无名旧镖到底送的是什么？
- 委托人是谁？
- 收货人是谁？
- 为什么账本被撕？
- 老镖头是死了、逃了、藏起来了，还是成了幕后势力的一部分？
- 旧镖失败了吗，还是其实成功送到了？
- 镖局的衰败是因为失镖、背锅、背叛，还是主动隐瞒真相？
- 这趟旧镖为什么会成为如今江湖变乱的起点？
- 玩家最终是要重现这趟镖、追回这趟镖、公开真相，还是亲手毁掉它？

## 9. 章节区域扩充方向

后续可以按商路区域划分章节，每个区域对应不同镖种、敌人、势力和剧情主题。

### 9.1 第一章：黑风山道

主题：重新开张。

主要镖种：普通镖、药镖、粮镖、小型人镖。

敌人方向：山匪、黑店、流民盗、路霸。

剧情作用：让玩家知道这家镖局已经不被人尊重，旧镖旗已经镇不住路上的人。

核心感觉：镖旗还在，但没人怕它了。

### 9.2 第二章：渡鸦镇水路

主题：规矩与黑市。

主要镖种：暗镖、赎镖、水路货。

敌人方向：水寇、黑市中人、假船夫、私盐帮。

剧情作用：让玩家接触地下交易和暗镖规则。

核心感觉：有些货不能见光，有些人也不能。

### 9.3 第三章：白石官道

主题：官府不一定代表秩序。

主要镖种：官镖、案卷、囚犯、人证。

敌人方向：假官差、追兵、门客、官府势力。

剧情作用：让玩家发现旧镖案可能被官方掩盖。

核心感觉：官印压得住百姓，压不住真相。

### 9.4 第四章：旧商路

主题：过去的残骸。

主要镖种：死镖、遗物镖、空镖。

敌人方向：旧镖师、残帮、守墓人、复仇者。

剧情作用：开始正面触及旧镖案。

核心感觉：这条路不是没人走，而是走过的人都不愿再提。

### 9.5 第五章：封门关

主题：交最后一趟镖。

主要镖种：终局镖。

敌人方向：各方势力汇聚。

剧情作用：玩家决定镖局最终守什么。

核心感觉：这一次，送到哪里已经不重要，重要的是要不要继续送。

当前暂不展开。

- 为什么来到这家镖局；

## 13. 当前版本结论

本版本正式确定：

1. 游戏世界以“镖局押镖”为核心背景；
2. 玩家拥有并经营一家濒临倒闭的老镖局；
3. 每一次 Run 都是一趟镖；
4. 镖种包括普通镖、人镖、暗镖、死镖、急镖、官镖、赎镖、空镖等；
5. 游戏的长期主线围绕多年前的“无名旧镖”展开；
6. 镖局经营的核心资源不只是银两，而是信用；
7. 后续人物、卡牌、遗物、事件、敌人、章节都应优先服务这一背景，而不是继续沿用早期临时武侠设定。
